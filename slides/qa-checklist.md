# Slide QA Checklist

全ページを書き出し、実寸に近いサイズで目視する。自動検査だけで完了としない。

## 目的と結論

- [ ] 誰に、何を判断・理解・実行してもらう資料か明確
- [ ] 冒頭で今回の問いが分かる
- [ ] 結論が問いへ直接答えている
- [ ] 最終ページに判断事項または次のアクションがある

## ストーリー

- [ ] タイトルだけを順に読んでも論理がつながる
- [ ] 1枚につき主要な主張が1つ
- [ ] 前後に論理の飛躍がない
- [ ] 同じ結論を言い換えて繰り返していない

## 正確性

- [ ] 事実・解釈・提案が区別されている
- [ ] 推測や未確認事項を断定していない
- [ ] 数値、単位、期間、母数が正しい
- [ ] グラフと本文の数字が一致している
- [ ] 架空のデータ、引用、成果がない
- [ ] 外部の主張、データ、画像に出典がある

## 文章

- [ ] タイトルはテーマ名でなく結論型
- [ ] 「〜について」など禁止表現がない
- [ ] 箇条書きは原則3〜5項目
- [ ] 抽象語だけで説明を終えていない
- [ ] 誤字、表記揺れ、不自然な日本語がない
- [ ] 豊藏が自然に口にできる表現になっている

## レイアウト

- [ ] 左右余白、タイトル位置、本文開始位置が揃っている
- [ ] 意図しない重なり、文字切れ、画像切れがない
- [ ] 1行想定のタイトルが不自然に折り返していない
- [ ] 小さなカードを過剰に敷き詰めていない
- [ ] 同じ構図が意図なく3枚以上続いていない

## 色・文字

- [ ] `theme/design.json`のトークンを使っている
- [ ] 白/navy/gray/teal中心、orangeは限定使用
- [ ] Tealを前進・次の一手に使っている
- [ ] 色だけで意味を伝えていない
- [ ] 本文は原則17pt以上
- [ ] 背景と文字のコントラストが十分

## 画像

- [ ] `slides/image-policy.md`の優先順位で選んだ
- [ ] ロゴは`assets/logo.png`を後処理で合成した
- [ ] AI生成ロゴ、AI生成の正確な数字・グラフ・UIがない
- [ ] 顔、手、主要要素の不自然な切れがない
- [ ] ぼけ、歪み、文字化けがない
- [ ] 権利と出典を確認した

## 最終出力

- [ ] 全ページをレンダリングして目視した
- [ ] 最終形式でフォント置換や崩れがない
- [ ] ページ番号、日付、会社名、機密区分が一貫している
- [ ] ファイル名とバージョンが正しい
- [ ] 3秒で各ページの用途が分かる
- [ ] 30秒で「次に何をするか」を説明できる
