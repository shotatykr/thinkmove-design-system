# Diagnostic Cockpit

診断・監査・分析レポートのテイスト。
GSC、GA4、SEO、LLMO、コンテンツ棚卸しなど、数字を見ながら意思決定する資料に使う。

## Use When

- SEO診断、GSC/GA4分析、LLMO監査
- 月次レポートや改善優先度の整理
- 「どこから手をつけるか」を決めたい資料

## Do Not Use When

- 初回の思想説明やブランド紹介
- 登壇の導入スライド
- 数字がまだ確認できていない段階の仮説資料

## Visual Grammar

- 背景は `bg-alt`
- KPIカード、順位表、優先度マップ、進捗バーを組み合わせる
- 情報密度は高くてよいが、視線の入口を左上に固定する
- 右上ロゴは小さく。ダッシュボードUIの邪魔をしない
- 赤・緑の強い信号色は避ける。Teal / Navy / Gray で状態を示す

## Layout Patterns

- Executive Summary: 3 KPI + 優先度マップ + 次アクション
- Audit: 観点別スコア + 検出課題 + 対応優先度
- Monthly: 前月比 + 仮説 + 次月の検証項目
- Triage: Impact / Effort / Confidence の整理

## Copy Example

```text
診断結果サマリー
止まっているのは施策量ではなく、優先順位の合意。

最初に直す:
検索意図とCTAの接続

次に見る:
流入後の回遊とCV導線

保留:
記事本数の追加。根拠が出るまで増やさない。
```

## Imagegen Use

- 基本は使わない
- レポート表紙にだけ、抽象ではなく「実務の場面」が必要なら使う
- グラフや表は生成画像にしない。必ず資料側で描画する

## QA Checklist

- [ ] KPIが装飾ではなく判断に接続している
- [ ] 次の一手が3つ以内に絞られている
- [ ] 出典や計測期間を入れられる余地がある
- [ ] スコアだけで終わらず、保留判断も明記できる
- [ ] 情報は多いが、視線の順番が崩れていない
