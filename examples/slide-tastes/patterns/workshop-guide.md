# Workshop Guide

研修・ワークショップ・実務ガイドのテイスト。
「講義を聞く資料」ではなく、その場で手を動かすための資料にする。

## Use When

- AI研修、SEO研修、ワークショップ
- 演習、チェックリスト、手順化
- 参加者が持ち帰って翌日使う資料

## Do Not Use When

- 経営層向けの短い意思決定資料
- 詳細な数値監査レポート
- 強い思想を語る登壇資料

## Visual Grammar

- 背景は白または `cta-light`
- ステップ、チェックリスト、入力欄を明確に分ける
- 1スライド内に「読む場所」と「書く場所」を作る
- Teal は進行中のステップや演習欄に使う
- 右上ロゴ。研修資料でもブランド署名は省略しない

## Layout Patterns

- Step-by-step: 4ステップ以内
- Exercise: 問い / 入力欄 / 共有ポイント
- Checklist: 実行前 / 実行中 / 実行後
- Facilitation: 進行メモ + 参加者の作業欄

## Copy Example

```text
AIに任せる前に、判断材料を渡す。

Step 1:
一次情報を集める

Step 2:
未決事項を分ける

Step 3:
AIに叩き台を作らせる

Step 4:
人間が公開判断をする
```

## Imagegen Use

- 参加者のワーク風景、手元、ホワイトボードなどの補助ビジュアルに使う
- 手順・チェックリスト・入力欄は生成画像にしない
- 漫画的に軽くしたいときは、4コマ素材として使う

## QA Checklist

- [ ] 参加者が次に何をすればよいか分かる
- [ ] 読むだけでなく、書く・選ぶ・判断する場所がある
- [ ] 講師向けの意図が本文に混ざっていない
- [ ] 1ステップが大きすぎない
- [ ] 持ち帰って再利用できる
