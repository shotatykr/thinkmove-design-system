# Keynote Narrative

LT・セミナー・思想整理のテイスト。
提案書より余白を広く取り、言葉の強さで引っ張る。ただし、派手に煽らない。

## Use When

- LT、セミナー、カンファレンス登壇
- 冒頭の問題提起、章扉、締めのメッセージ
- ThinkMove の思想や世界観を伝える資料

## Do Not Use When

- 詳細な見積・支援範囲を説明するページ
- KPIや分析表が主役の資料
- 研修の手順ページ

## Visual Grammar

- 大きな余白 + 強い1文
- Navy の面を使ってよいが、暗くしすぎない
- ロゴは右上。章扉だけ右下も許可
- 本文は少なく、補助情報は脚注や小さな注記に逃がす
- 画像を使う場合は情景として使い、スライド全体を説明させない

## Layout Patterns

- Problem Statement: 大きな問い + 小さな補足
- Section Divider: 章番号 + 章タイトル + 余白
- Narrative Arc: 止まる / 見る / 動かす
- Closing: 1文 + 次の行動

## Copy Example

```text
施策は回っている。
でも、判断だけが止まっている。

AIで全部を自動化するのではなく、
人間の一次情報と判断を増幅する。
```

## Imagegen Use

- 情景写真、セミナーの空気、仕事机、会議前の緊張感などに使う
- 抽象的な光やグラデーションだけの背景は避ける
- 文字を画像の中に入れない。言葉は資料側で置く

## QA Checklist

- [ ] 1枚の言葉が強い
- [ ] 余白は大きいが、意味がある
- [ ] 派手な演出で煽っていない
- [ ] 章の役割が一瞬で分かる
- [ ] 次のスライドへ視線が流れる
