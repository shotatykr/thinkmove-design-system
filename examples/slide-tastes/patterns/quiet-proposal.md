# Quiet Proposal

提案書・会社紹介・営業資料の基本テイスト。
ThinkMove の標準にもっとも近い。「清潔なコンサル資料」だが、冷たくしすぎない。

## Use When

- 初回提案、支援提案、会社紹介
- 料金・支援範囲・進め方を説明する
- 経営者または1〜2名のマーケ担当に、落ち着いて判断材料を渡す

## Do Not Use When

- 数値診断や監査結果が主役の資料
- 登壇用に強い余白と大きな言葉が必要な資料
- 演習・ワークが中心の研修資料

## Visual Grammar

- 背景は `bg` または白
- 上部に小さな context label、右上にロゴ
- H1 は大きすぎず、1行〜2行で断言する
- 右側または下部に、判断材料のカードを3つ置く
- Teal は「次へ進む」要素にだけ使う
- Orange は注記や重要数値の1点アクセントに留める

## Layout Patterns

- Cover: 左に大きな提案タイトル、右に支援の要約カード
- Section: 章タイトル + 3つの判断材料
- Offer: 課題 / 支援内容 / 次の一手
- Comparison: 採用 / 外注 / ThinkMove の比較

## Copy Example

```text
採用する前に。外注する前に。
止まっている判断を、横で一緒に動かす。

現状:
施策は回っているが、次の優先順位が決まらない。

支援:
調査、叩き台、検証、報告を1つの流れで進める。

次の一手:
最初の2週間で、判断材料の棚卸しから始める。
```

## Imagegen Use

- 代表写真やオフィスの自然な情景が必要な場合に使う
- 抽象的なグラデーション背景は使わない
- 生成画像は右側の小さな補助ビジュアルに留める

## QA Checklist

- [ ] 右上にロゴがある
- [ ] 1枚の主論点が1つに絞られている
- [ ] 数字、根拠、次の一手のどれかが入っている
- [ ] 余白はあるが、情報が薄くなっていない
- [ ] `worldview/voice.md` の禁止表現がない
