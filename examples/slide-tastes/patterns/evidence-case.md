# Evidence Case

顧客事例・改善報告・成果共有のテイスト。
「すごい成果」ではなく、何を見て、何を変え、何が動いたかを静かに示す。

## Use When

- 顧客事例、導入事例、改善報告
- 社内向けの結果共有
- 営業資料内で支援の再現性を示す

## Do Not Use When

- 数字や固有名詞を出せない事例
- まだ検証前の仮説
- 事例より思想やコンセプトを見せたい章

## Visual Grammar

- 左に claim、右に evidence / action の縦積み
- 大きな数値を1〜2個だけ見せる
- 数字の横に必ず「何を意味するか」を添える
- 顧客ロゴや人物写真がある場合は小さく、根拠の補助として置く
- Orange は「変化点」1箇所だけ

## Layout Patterns

- Claim / Evidence / Action
- Before / Intervention / After
- Context / Decision / Result
- Quote + Evidence

## Copy Example

```text
記事を増やす前に、判断の詰まりをほどいた。

Evidence:
自然検索CV 142%
主要導線クリック 3.1x

Action:
検索意図ごとにCTAを分け、既存記事を再編集。
新規記事の追加は、導線改善後に絞って実施。
```

## Imagegen Use

- 事例の守秘が必要なとき、匿名化した業務シーンを生成する
- 実在顧客のロゴ・人物・画面を生成で代替しない
- 数値と本文は必ず資料側で組む

## QA Checklist

- [ ] claim が一般論になっていない
- [ ] evidence に期間・対象・変化がある
- [ ] action が再現可能な粒度で書かれている
- [ ] 数字だけで煽っていない
- [ ] 守秘に配慮している
